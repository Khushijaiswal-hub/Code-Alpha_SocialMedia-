# Social Media Platform 🚀

A full-stack social media platform where users can create accounts, share posts, upload images, like posts, comment, and connect with other users.

## Features ✨
- User Authentication (Login & Signup)
- Create, Edit, and Delete Posts
- Upload Images
- Like and Comment on Posts
- User Profile Page
- Responsive Design
- Secure Backend API
- Database Integration

## Tech Stack 💻

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB
